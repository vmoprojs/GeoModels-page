An R package for spatial statistics

Flexible spatial modelling.
Built for large data.

GeoModels provides simulation, likelihood-based inference, model diagnostics and prediction for Gaussian and non-Gaussian spatial and spatiotemporal random fields.

Explore rich marginal distributions and correlation families, including Matérn, generalized Wendland and Kummer models, with computational tools for large point-referenced datasets.

A unified workflow

From random-field simulation to prediction

A common interface lets users work with a wide range of distributions and correlation models without changing their overall analysis workflow.

01 / SIMULATE

Simulate

Generate Gaussian and non-Gaussian fields, with exact or accelerated simulation methods.

GeoSim() · GeoSimapprox()
02 / ESTIMATE

Fit & infer

Use full likelihood where feasible, or pairwise composite likelihood for large datasets.

GeoFit() · GeoVarest()
03 / DIAGNOSE

Check the model

Examine fitted marginal distributions, residuals and spatial or space–time semivariograms.

GeoResiduals() · GeoQQ()
04 / PREDICT

Predict

Compute optimal linear predictions and local predictions on large spatial datasets.

GeoKrig() · GeoKrigloc()
Getting started

Your first GeoModels analysis

Install the current CRAN release and try a compact example covering simulation, parameter estimation, diagnostic assessment and prediction.

Installation

install.packages("GeoModels")

  • Works with R 4.4.0 or later according to the current CRAN release.
  • Choose model for the marginal family and corrmodel for dependence.
  • Use CorrParam() and MargParam() to inspect model parameters.

The example is intentionally small and uses full likelihood. For larger datasets, see the composite-likelihood methods and case studies below.

Browse function documentation ↗
R · simulate → fit → diagnose → predict
library(GeoModels)
set.seed(6)
coords <- cbind(runif(250), runif(250))

# 1. Simulate a Gaussian spatial random field
param <- list(mean = 0, sill = 1, nugget = 0,
              scale = 0.12, smooth = 0.5)
y <- GeoSim(coordx = coords, model = "Gaussian",
            corrmodel = "Matern", param = param)$data

# 2. Fit a Matérn model by full likelihood
fit <- GeoFit(data = y, coordx = coords,
              model = "Gaussian", corrmodel = "Matern",
              likelihood = "Full", type = "Standard",
              start = list(mean = 0, sill = 1, scale = 0.1),
              fixed = list(nugget = 0, smooth = 0.5))

# 3. Check the marginal fit
res <- GeoResiduals(fit)
GeoQQ(res)

# 4. Predict on a new spatial grid
loc <- as.matrix(expand.grid(seq(0, 1, length.out = 30),
                             seq(0, 1, length.out = 30)))
pr <- GeoKrig(fit, loc = loc, mse = TRUE)

Scope and important distinctions. GeoModels focuses on point-referenced data, not native areal models. Supported estimation and simulation methods vary by marginal family, correlation model and observation design. On the sphere, covariance validity depends on the choice of geodesic or chordal distance; in particular, an unrestricted Euclidean Matérn correlation is not automatically valid with great-circle distance. For non-Gaussian fields, optimal linear prediction need not equal the conditional-mean predictor.
Computational methods

Methods for large and complex datasets

GeoModels combines statistical flexibility with numerical strategies that avoid dense, global covariance operations whenever possible and appropriate.

01

Full likelihood

Exact likelihood-based fitting for distributions and sample sizes where multivariate likelihood evaluation is feasible.

GeoFit() · likelihood="Full"
02

Neighbour WCLP

Weighted pairwise likelihood using spatial nearest neighbours; the number of evaluated contributions is proportional to n for a fixed neighbourhood size.

GeoFit() · neighb
03

Stochastic pair thinning

Randomly retain a fraction of candidate neighbour pairs to reduce the computational cost of composite-likelihood evaluations.

thin_method="Bernoulli"
04

Fast simulation

Circulant embedding on suitable grids and spectral turning bands for many irregularly located spatial observations.

GeoSimapprox() · CE / TB
05

Uncertainty quantification

Obtain composite-score variability estimates via parametric bootstrap, without reoptimizing the model in each simulation.

GeoVarest()
06

Local linear prediction

Predict using selected spatial and temporal neighbourhoods; prediction is based on the covariance of the observed random field.

GeoKrigloc() · neighb / maxtime

Computational advantages are conditional on model and design assumptions; they are not universal speed guarantees. In particular, the fast temporal circulant-embedding approach described in the JSS manuscript uses a separable, complete site–time design without independent nugget.
